Project Description : The Movie Ticket Booking & Snack Ordering System is an online platform that allows customers to browse currently running and upcoming movies, select preferred showtimes and seats, book tickets, and optionally order snacks to be picked up at the cinema counter. The system supports multiple screens/auditoriums, tiered seat categories (Silver, Gold, Platinum), multiple payment modes, discount coupons, and automated booking confirmations via email/SMS. An Admin manages the movie catalogue, showtimes, seat configuration, snack inventory, and generates reports.

How to run the code : 
1.Clone the repo(git clone https://github.com/Agenthardhik/23CSE111_CaseStudy_D13.git)
2.Open project in Eclipse or IntelliJ
3.Go to Main.java
4.Click Run Code
5.Put all files in the same folder,then run:
javac *.java
java Main
